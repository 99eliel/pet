Como interpretar

Taxa de erro = respostas incorretas ÷ respostas recebidas naquela pergunta × 100. Como as perguntas são sorteadas, cada uma pode ter quantidades diferentes de respostas.

Os dados representam partidas realizadas no estande, não uma amostra estatisticamente representativa da população. Uma pessoa pode participar mais de uma vez.

A idade média considera somente as partidas com idade informada. Os registros antigos sem idade são excluídos desse cálculo; uma pessoa pode jogar mais de uma vez.

Partidas anteriores à implantação do registro por pergunta não podem ser reconstruídas a partir do ranking antigo. Resultados ainda não sincronizados do tablet não aparecem no relatório online.
